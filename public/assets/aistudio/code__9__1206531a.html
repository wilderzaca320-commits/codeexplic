Consultas Comunes & Explicación Semántica por IA

Pregunta en lenguaje natural para obtener la consulta SQL validada sobre este modelo relacional

Query SQL Generada & Optimizada 
SELECT
    DATE_TRUNC('month', o.created_at) AS billing_month,
    o.currency,
    COUNT(DISTINCT o.id) AS total_successful_orders,
    SUM(o.amount_cents) / 100.0 AS gross_revenue,
    COALESCE(SUM(p.fee_cents) / 100.0, 0) AS gateway_fees
FROM
    orders o
INNER JOIN
    payments_ledger p ON p.order_id = o.id
WHERE
    o.status = 'COMPLETED'
    AND p.state = 'SETTLED'
    AND o.created_at >= NOW() - INTERVAL '12 months'
GROUP BY
    DATE_TRUNC('month', o.created_at),
    o.currency
ORDER BY
    billing_month DESC;
forum Desglose Semántico (Línea por Línea)
1. DATE_TRUNC('month', created_at)

Agrupa las ventas en bloques mensuales continuos respetando la zona horaria UTC del cluster.

2. INNER JOIN payments_ledger ON p.order_id = o.id

Garantiza consistencia contable: solo suma pedidos que tengan una transacción bancaria respaldada en el ledger inmutable.

3. WHERE status = 'COMPLETED' AND state = 'SETTLED'

Aprovecha el índice parcial compuesto sin escanear reembolsos o pagos pendientes.
