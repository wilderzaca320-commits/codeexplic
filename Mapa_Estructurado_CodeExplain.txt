5.3 MOTOR DE IA

  Modelo          : gemini-2.5-flash
  SDK             : @google/genai
  Niveles         : basico, intermedio, avanzado (LEVEL_PROMPTS en server.ts)
  Prompt actual   : rol + nombre del proyecto + descripcion + stack + nivel
  Lo que NO tiene : restricciones de "no inventes", citas, formato de salida,
                    temperatura, maxTokens ni timeout.
  Modo respaldo   : motor heuristico local si no hay key, hay 429 o hay error.

  Ramas del motor heuristico (E-01):
+---------------------------+-----------------------------------------------+
| SI LA PREGUNTA MENCIONA   | RESPONDE SOBRE                                |
+---------------------------+-----------------------------------------------+
| stripe, pago, webhook     | Redlock, idempotencia, order.settled          |
| jwt, auth, seguridad      | RS256, rotacion de tokens, RBAC               |
| cualquier otra cosa       | Analisis generico del proyecto                |
+---------------------------+-----------------------------------------------+

  Aviso: el motor heuristico inventa cifras (34% de acoplamiento, 1.2 ms p95,
  RSA-4096) y las presenta como datos del proyecto. Es el riesgo R-07 del ARD.

 6. CONTRATOS (la union entre frontend y backend)
================================================================================

6.1 ProjectDigest - lo que el navegador extrae del ZIP
  Ya esta escrito en src/lib/analyzeProject.ts.
  {
    name            : string            nombre del proyecto
    files           : [{path, size}]    inventario completo
    totalFiles      : number
    codeFiles       : number
    totalSloc       : number
    languages       : {lenguaje: n}     conteo por lenguaje
    dependencies    : string[]          hasta 30
    entryCandidates : string[]          index, main, app, server
    textSample      : string            hasta 48 KB de codigo
    sourceKind      : 'zip' | 'url'
  }
  Limites reales del motor: 300 archivos de texto, 4 MB de texto total,
  6 KB por archivo en la muestra, 48 KB de muestra, 30 dependencias.
  Se omiten node_modules, .git, binarios, .DS_Store y thumbs.db.

6.2 ProjectAnalysis - lo que el servidor debe devolver
  {
    name        : string
    description : string
    languages   : string[]
    astHealth   : number     0-100
    debtHours   : number
    spofCount   : number
    reposCount  : number
    summary     : string
    model       : string     'gemini-2.5-flash' | 'codeexplain-core'
  }

6.3 Contrato del chat (E-01)
  Request : { message, level, history[], projectContext }
  Response: { reply, level, model }

6.4 Contrato de explicacion (E-02)
  Request : { code, level }
  Response: { summary, steps[{title, line, description}], advisorTip }

6.5 Contrato de documentacion (E-03)
  Request : { docType: 'readme'|'openapi'|'c4', projectContext }
  Response: { content, type }

6.6 Contrato de analisis (E-04) - PENDIENTE
  Request : ProjectDigest (6.1)
  Response: ProjectAnalysis (6.2)
  Errores : 400 digest invalido, 413 digest demasiado grande,
            502 proveedor de IA caido (se responde con fallback).

6.7 Contrato de analisis por URL (E-05) - PENDIENTE
  Request : { url, branch }
  Response: ProjectAnalysis (6.2)
  Errores : 400 URL invalida, 422 repo privado o inaccesible,
            504 timeout de descarga.

  Importante: el cliente YA llama a /api/analyze y /api/analyze-url desde
  analyzeDigest() y analyzeUrl(). Hoy nadie las usa porque UploadModal no
